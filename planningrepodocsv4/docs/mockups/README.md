# Mockups — review guide

Two clickable design mockups, representing two different products. Review
on your phone — that's where ~90% of real traffic will come from (links
opened inside the Facebook and Reddit apps).

## How to view

- **Easiest**: open the private preview links Claude published (see the
  session conversation, or `claude.ai/code/artifacts` gallery). They're
  visible only to Aimee unless shared from the page's share menu.
- **Locally**: open either `.html` file in any browser. (The files are
  authored in Claude Artifact format — no `<html>` wrapper — but render
  fine standalone.)

## Mockup A v4 — APPROVED DIRECTION (`mockup-a-matchday-hub.html`)

**v4 (2026-08-29):** page ground flipped to warm light (requested — some
older fans dislike dark themes) while the cinematic night-match tiles stay
as the imagery; mobile nav tightened. This version was turned into the
production site (see the `springboksallblacks2026.github.io` repo).

### Earlier: v3 notes

**"All Events · Springboks v All Blacks 2026 · Baltimore"** — a pure event
aggregator. v3 (2026-08-29) restyles the imagery for the test-rugby fan
profile after Aimee rejected the v2 cartoon look: a cinematic
**floodlit-night art system** (fire-glow tailgate, screen-glow watch party,
lamplit cobblestones, gold crab crest, dawn Fort McHenry, glowing stadium
bowl) with film grain and silhouettes; Bebas Neue condensed display type;
kickoff shown in Baltimore / Johannesburg / Auckland time. Kept from the
approved v2 structure: visitbaltimore-style cards with date badges and
prominent **"View Original"** buttons; matchday essentials (now with their
own image tiles); full-width gold **"Open Map"** buttons on the city guide;
no on-site posting; "group links coming soon" notes; ticket links.

Note on visuals: the artifact preview cannot load external images, so the
tiles are an original SVG art system — production can keep them (zero
licensing risk, fully consistent) or swap in licensed night-match
photography with the same treatment.
